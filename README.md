# Immortal Mod Suite

Bản mod tổng hợp cho Tale of Immortal của Vyyy.

Tải gói cài tại mục Releases. Cần có game và MelonLoader tương thích.

Thoát game, giải nén gói vào thư mục game để DLL nằm tại `Mods/ImmortalModSuite.dll`. Giữ nguyên `UserData` để bảo toàn thiết lập riêng. Gói phát hành không chứa save game.
